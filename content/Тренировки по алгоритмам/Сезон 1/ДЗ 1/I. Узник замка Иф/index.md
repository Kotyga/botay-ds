# Условие

За многие годы заточения узник замка Иф проделал в стене прямоугольное отверстие размером $D \times E$.

Замок сложен из кирпичей размером $A \times B \times C$.

Определите, сможет ли узник выбрасывать кирпичи в море через это отверстие. При этом стороны кирпича должны быть параллельны сторонам отверстия.

## Формат ввода

Вводятся пять чисел $A$, $B$, $C$, $D$ и $E$, каждое в отдельной строке:

- $A$, $B$, $C$ — размеры кирпича;
- $D$, $E$ — размеры отверстия.

## Формат вывода

Выведите:

- `YES`, если кирпич можно выбросить через отверстие;
- `NO` — в противном случае.

## Пример 1

**Ввод:**

```text
1
1
1
1
1
```

**Вывод:**

```text
YES
```

## Пример 2

**Ввод:**

```text
2
2
2
1
1
```

**Вывод:**

```text
NO
```

# Решение

```python
a, b, c, d, e = map(int, open(0).read().split())

x, y, _ = sorted((a, b, c))
d, e = sorted((d, e))

print('YES' if x <= d and y <= e else 'NO')
```
