# Условие

Даны три натуральных числа. Требуется определить, можно ли построить треугольник с такими длинами сторон.

Треугольник — это три точки, не лежащие на одной прямой.

Если треугольник построить возможно, выведите строку `YES`, иначе выведите строку `NO`.

## Формат ввода

Вводятся три натуральных числа — длины сторон треугольника.

Каждое число записано в отдельной строке.

## Формат вывода

Выведите ответ:

- `YES`, если треугольник можно построить;
- `NO`, если треугольник построить нельзя.

## Пример 1

**Ввод:**

```text
3
4
5
```

**Вывод:**

```text
YES
```

## Пример 2

**Ввод:**

```text
3
5
4
```

**Вывод:**

```text
YES
```

## Пример 3

**Ввод:**

```text
4
5
3
```

**Вывод:**

```text
YES
```

# Решение

```python
a = int(input())
b = int(input())
c = int(input())

l1 = a+b
l2 = a+c
l3 = b+c

if l1 > c and l2 > b and l3 > a:
	print('YES')
else:
	print('NO')
```
