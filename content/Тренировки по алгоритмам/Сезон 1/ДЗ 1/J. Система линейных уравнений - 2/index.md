# Условие

Дана система линейных уравнений:

$$
\begin{cases}
ax + by = e, \\
cx + dy = f.
\end{cases}
$$

Требуется определить множество решений этой системы.

## Формат ввода

Вводятся шесть чисел — коэффициенты $a$, $b$, $c$, $d$, $e$ и $f$, каждое в отдельной строке.

## Формат вывода

Вывод зависит от множества решений системы:

- Если система не имеет решений, выведите:

  ```text
  0
  ```

- Если система имеет бесконечно много решений вида

  $$
  y = kx + b,
  $$

  выведите число `1`, а затем значения $k$ и $b$:

  ```text
  1 k b
  ```

- Если система имеет единственное решение $(x, y)$, выведите число `2`, а затем значения $x$ и $y$:

  ```text
  2 x y
  ```

- Если система имеет бесконечно много решений вида

  $$
  x = x_0,
  $$

  выведите число `3`, а затем значение $x_0$:

  ```text
  3 x0
  ```

- Если система имеет бесконечно много решений вида

  $$
  y = y_0,
  $$

  выведите число `4`, а затем значение $y_0$:

  ```text
  4 y0
  ```

- Если решением системы является любая пара чисел $(x, y)$, выведите:

  ```text
  5
  ```

## Пример 1

**Ввод:**

```text
1
0
0
1
3
3
```

**Вывод:**

```text
2 3 3
```

## Пример 2

**Ввод:**

```text
1
1
2
2
1
2
```

**Вывод:**

```text
1 -1 1
```

## Пример 3

**Ввод:**

```text
0
2
0
4
1
2
```

**Вывод:**

```text
4 0.5
```

# Решение

```python
a, b, c, d, e, f = map(float, open(0).read().split())

if (a == 0 and b == 0 and e != 0) or \
   (c == 0 and d == 0 and f != 0):
    print(0)

elif a == 0 and b == 0 and c == 0 and d == 0:
    print(5)

else:
    determinant = a * d - b * c

    if determinant != 0:
        x = (e * d - b * f) / determinant
        y = (a * f - e * c) / determinant
        print(2, x, y)

    else:
        if a * f != c * e or b * f != d * e:
            print(0)

        else:
            if a != 0 or b != 0:
                A, B, E = a, b, e
            else:
                A, B, E = c, d, f

            if A == 0:
                print(4, E / B)

            elif B == 0:
                print(3, E / A)

            else:
                k = -A / B
                n = E / B
                print(1, k, n)
```
