# Теория

## Проблема «мёртвых» нейронов

ReLU возвращает ровно ноль для любого отрицательного входного значения:

$$
\operatorname{ReLU}(x) = \max(0, x)
$$

Это означает, что если значение нейрона до применения функции активации отрицательно для всех обучающих примеров, его градиент всегда равен нулю. Такой нейрон перестаёт обновляться, навсегда становится «мёртвым» и больше не вносит никакого вклада в работу сети.

Это происходит чаще, чем можно было бы ожидать:

- Большое обновление градиента может сделать смещение настолько отрицательным, что значение до активации всегда будет меньше нуля.
- При высокой скорости обучения многие нейроны могут «умереть» уже на первых шагах обучения.
- После того как нейрон «умер», восстановить его невозможно, поскольку градиент в отрицательной области в точности равен нулю.

## Leaky ReLU

Leaky ReLU изменяет отрицательную часть функции: вместо горизонтального участка с нулевым значением она получает небольшой наклон.

$$
\operatorname{LeakyReLU}(x) =
\begin{cases}
x, & x \geq 0, \\
\alpha x, & x < 0.
\end{cases}
$$

- Для положительных входных значений функция ведёт себя точно так же, как ReLU: выход равен входу.
- Для отрицательных входных значений функция умножает вход на небольшую константу $\alpha$, обычно равную $0{,}01$.

Эта «утечка» мала, но крайне важна. Вместо того чтобы полностью блокировать отрицательные сигналы, функция пропускает их небольшую часть.

## Роль параметра $\alpha$

Параметр $\alpha$ определяет наклон функции для отрицательных входных значений:

- $\alpha = 0$ — стандартная ReLU, без какой-либо «утечки».
- $\alpha = 0{,}01$ — наиболее распространённое значение по умолчанию. Отрицательные входные значения уменьшаются в 100 раз.
- $\alpha = 0{,}1$ или $\alpha = 0{,}2$ — более сильная «утечка». Используется, когда требуется обеспечить больший поток градиента для отрицательных входных значений.
- $\alpha = 1$ — функция превращается в $f(x) = x$, то есть в тождественное преобразование. Фактически функция активации отсутствует.
- $\alpha > 1$ — наклон отрицательной части становится больше наклона положительной части. Это необычный, но допустимый вариант.

Главная идея заключается в том, что при $\alpha \neq 0$ нейрон не может окончательно «умереть». Даже если значение до активации отрицательно, градиент остаётся ненулевым и равен $\alpha$, поэтому веса всё ещё могут обновляться.

## Градиент

Производная Leaky ReLU имеет следующий вид:

$$
\frac{d}{dx}\operatorname{LeakyReLU}(x) =
\begin{cases}
1, & x \geq 0, \\
\alpha, & x < 0.
\end{cases}
$$

Сравним это с ReLU, производная которой для отрицательных входных значений в точности равна нулю. У Leaky ReLU производная в отрицательной области равна $\alpha$: это малое, но ненулевое значение.

Во время обратного распространения ошибки:

- **В положительной области** градиент проходит без ослабления — он умножается на 1.
- **В отрицательной области** градиент уменьшается в соответствии с коэффициентом $\alpha$, например до $0{,}01$ от исходного значения, но продолжает распространяться.

Это означает, что градиенты могут достигать каждого нейрона независимо от знака входного значения.

## Параметрическая ReLU — PReLU

Естественное расширение Leaky ReLU заключается в том, чтобы не фиксировать $\alpha$ как константу, а сделать его обучаемым параметром. Такая функция называется PReLU — Parametric ReLU, или параметрическая ReLU:

$$
\operatorname{PReLU}(x) =
\begin{cases}
x, & x \geq 0, \\
\alpha x, & x < 0.
\end{cases}
$$

Формула остаётся прежней, но теперь параметр $\alpha$ обучается с помощью обратного распространения ошибки так же, как веса и смещения. Сеть может самостоятельно подобрать оптимальный наклон для каждого слоя или даже для каждого отдельного нейрона.

- Если оптимальное значение $\alpha$ близко к 0, PReLU учится вести себя как обычная ReLU.
- Если оптимальное значение $\alpha$ близко к 1, слой становится почти линейным.
- На практике обученные значения $\alpha$ часто оказываются в диапазоне от $0{,}1$ до $0{,}3$.

## Где применяется Leaky ReLU

### Генеративно-состязательные сети

В GAN Leaky ReLU является стандартной функцией активации для сетей-дискриминаторов. В статье о DCGAN для дискриминатора рекомендовалось использовать значение:

$$
\alpha = 0{,}2
$$

### Обнаружение объектов

Архитектуры для обнаружения объектов, такие как YOLO, используют Leaky ReLU.

### Глубокие сети с проблемой «мёртвых» нейронов

Если после обучения у большого количества нейронов выходные значения всегда равны нулю, самый простой способ исправить ситуацию — заменить ReLU на Leaky ReLU.

## Реализация на numpy:

```python
import numpy as np

def leaky_relu(x, alpha=0.01):
    """
    Vectorized Leaky ReLU implementation.
    """
    x = np.asarray(x, dtype=float)
    return np.where(x >= 0, x, alpha * x)
```
