# Теория

ReLU (Rectified Linear Unit) определяется следующим образом:

$$
\operatorname{ReLU}(x)=\max(0,x).
$$

График функции напоминает хоккейную клюшку: для всех отрицательных входных значений он остаётся на нуле, а для положительных представляет собой прямую с угловым коэффициентом $1$.

До появления ReLU стандартными функциями активации были сигмоида и гиперболический тангенс (`tanh`). Обе сжимают входные значения до ограниченного диапазона:

- сигмоида — до $(0,1)$;
- `tanh` — до $(-1,1)$.

Они работали, но имели серьёзный недостаток — проблему исчезающих градиентов.

## Проблема исчезающих градиентов

- Сигмоида и `tanh` насыщаются при больших по модулю входных значениях: их выход почти не изменяется.
- В областях насыщения производная близка к нулю.
- Во время обратного распространения градиенты перемножаются при прохождении через множество слоёв.
- Почти нулевые производные на каждом слое приводят к экспоненциальному уменьшению градиента.
- Глубокие слои почти не обучаются, поскольку поступающий к ним градиент фактически равен нулю.

ReLU решает эту проблему для положительных входных значений:

- производная ReLU равна $1$ для всех $x>0$;
- градиенты проходят без изменений независимо от количества слоёв;
- глубокие сети обучаются намного быстрее, поскольку градиентный сигнал сохраняется.

У ReLU также есть практические преимущества:

- **Низкая вычислительная стоимость:** требуется лишь сравнение с нулём — без экспонент и делений.
- **Разреженная активация:** многие нейроны выдают ровно $0$, благодаря чему формируются разреженные представления. Разреженные сети эффективнее и часто лучше обобщают данные.
- **Простота реализации:** достаточно одной строки кода.

## Градиент ReLU

Производная, используемая при обратном распространении ошибки, имеет вид:

$$
\frac{d}{dx}\operatorname{ReLU}(x)=
\begin{cases}
1, & x>0, \\
0, & x<0.
\end{cases}
$$

>[!IMPORTANT]
> ReLU не является дифференцируемой в точке $x=0$, однако это практически не влияет на работу алгоритмов обучения, поскольку подобные точки имеют нулевую меру и редко встречаются во время оптимизации. На практике фреймворки обычно определяют производную в нуле как $0$, хотя некоторые используют $0.5$ или $1$.


Именно градиент, равный $1$ для положительных входных значений, делает ReLU настолько эффективной в глубоких сетях. Для сравнения: максимальный градиент сигмоиды равен всего $0.25$ и достигается при $x=0$. После прохождения через десять слоёв с сигмоидой градиент уменьшается примерно в $0.25^{10}\approx 10^{-6}$ раз.

## Проблема «мёртвых» нейронов

Главный недостаток ReLU заключается в том, что для отрицательных входных значений и выход, и градиент в точности равны нулю.

Если взвешенный вход нейрона отрицателен для каждого обучающего примера, нейрон никогда не выдаст ненулевое значение и не получит ненулевой градиент. Он навсегда становится «мёртвым».

### Как нейроны «умирают»

1. Большое обновление градиента изменяет веса так, что значение до применения активации всегда становится отрицательным.
2. Если оно отрицательно для всех входных данных, градиент всегда равен нулю, поэтому веса больше не обновляются.
3. До конца обучения нейрон больше не вносит никакого вклада в работу сети.

Это может происходить со значительной долей нейронов, особенно при высокой скорости обучения. В некоторых сетях «умирают» от $10\%$ до $40\%$ нейронов.

## Решения, основанные на ReLU

- **Leaky ReLU:** допускает небольшой градиент для отрицательных входных значений, используя $\alpha x$ вместо $0$.
- **ELU:** использует экспоненциальную кривую для отрицательных входных значений.
- **GELU и Swish:** гладкие приближения, градиент которых не становится строго равным нулю.
- **Тщательная инициализация:** правильная инициализация весов, например инициализация Хе, снижает вероятность того, что нейроны изначально окажутся в «мёртвой» области.

## Где применяется ReLU

ReLU — стандартная функция активации для большинства архитектур нейронных сетей:

- **Свёрточные сети (CNN):** AlexNet в 2012 году стала одной из первых успешных крупных моделей, использовавших ReLU. С тех пор почти все основные CNN применяют ReLU или один из её вариантов.
- **Полносвязные слои:** стандартный выбор для скрытых слоёв многослойных перцептронов (MLP).
- **Генеративные модели:** применяется в генераторах и дискриминаторах GAN.
- **Остаточные сети (ResNet):** ReLU используется после каждого остаточного блока.

ReLU применяется реже в следующих случаях:

- **Выходные слои:** если нужны ограниченные выходные значения, вместо ReLU используют сигмоиду или `softmax`.
- **Трансформеры:** в слоях прямого распространения обычно используются GELU или Swish.
- **Рекуррентные нейронные сети (RNN):** для рекуррентных связей обычно применяются `tanh` или сигмоида, поскольку ReLU может приводить к взрывному росту активаций в рекуррентных циклах.

## Реализация на numpy:

```python
import numpy as np

def relu(x):
    """
    Implement ReLU activation function.
    """
    x = np.asarray(x, dtype=float)
    return np.maximum(x, 0)
```
