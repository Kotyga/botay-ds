# Условие

Решите в целых числах уравнение:

$$
\sqrt{ax+b}=c,
$$

где $a$, $b$ и $c$ — заданные целые числа.

Требуется найти все целочисленные решения уравнения или сообщить, что решений нет.

## Формат ввода

Вводятся три целых числа $a$, $b$ и $c$, каждое в отдельной строке.

## Формат вывода

Выведите все целочисленные решения уравнения в порядке возрастания.

Если решений нет, выведите:

```text
NO SOLUTION
```

Если решений бесконечно много, выведите:

```text
MANY SOLUTIONS
```

## Пример 1

**Ввод:**

```text
1
0
0
```

**Вывод:**

```text
0
```

## Пример 2

**Ввод:**

```text
1
2
3
```

**Вывод:**

```text
7
```

## Пример 3

**Ввод:**

```text
1
2
-3
```

**Вывод:**

```text
NO SOLUTION
```

# Решение

```python
a = int(input())
b = int(input())
c = int(input())

if c < 0:
    print('NO SOLUTION')

elif a == 0:
    if b == c * c:
        print('MANY SOLUTIONS')
    else:
        print('NO SOLUTION')

else:
    numerator = c * c - b

    if numerator % a == 0:
        x = numerator // a
        print(x)
    else:
        print('NO SOLUTION')
```
