### A. Interactor

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 256 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |

#### Условие

Лена руководит разработкой тестирующей системы, в которой реализованы интерактивные задачи.

Для завершения очередной стадии проекта необходимо написать модуль, определяющий итоговый вердикт системы. Он зависит от:

- кода завершения задачи;
- вердикта интерактора;
- вердикта чекера.

Вердикты чекера и интерактора — целые числа от $0$ до $7$ включительно. Код завершения задачи — целое число от $-128$ до $127$ включительно.

Итоговый вердикт определяется по следующим правилам:

1. Если интерактор выдал вердикт `0`:
   - если программа завершилась с ненулевым кодом, итоговый вердикт равен `3`;
   - иначе итоговый вердикт равен вердикту чекера.

2. Если интерактор выдал вердикт `1`, итоговый вердикт равен вердикту чекера.

3. Если интерактор выдал вердикт `4`:
   - если программа завершилась с ненулевым кодом, итоговый вердикт равен `3`;
   - иначе итоговый вердикт равен `4`.

4. Если интерактор выдал вердикт `6`, итоговый вердикт равен `0`.

5. Если интерактор выдал вердикт `7`, итоговый вердикт равен `1`.

6. Во всех остальных случаях итоговый вердикт равен вердикту интерактора.

Требуется реализовать модуль, вычисляющий итоговый вердикт.

##### Формат ввода

Входные данные состоят из трёх строк:

1. целое число $r$ — код завершения задачи:

   $$
   -128 \le r \le 127;
   $$

2. целое число $i$ — вердикт интерактора:

   $$
   0 \le i \le 7;
   $$

3. целое число $c$ — вердикт чекера:

   $$
   0 \le c \le 7.
   $$

##### Формат вывода

Выведите одно целое число от $0$ до $7$ включительно — итоговый вердикт системы.

##### Пример 1

**Ввод:**

```text
0
0
0
```

**Вывод:**

```text
0
```

##### Пример 2

**Ввод:**

```text
-1
0
1
```

**Вывод:**

```text
3
```

##### Пример 3

**Ввод:**

```text
42
1
6
```

**Вывод:**

```text
6
```

##### Пример 4

**Ввод:**

```text
44
7
4
```

**Вывод:**

```text
1
```

##### Пример 5

**Ввод:**

```text
1
4
0
```

**Вывод:**

```text
3
```

##### Пример 6

**Ввод:**

```text
-3
2
4
```

**Вывод:**

```text
2
```
#### Решение
```python
r = int(input())
i = int(input())
c = int(input())

if i == 0:
    if r != 0:
        print(3)
    else:
        print(c)
elif i == 1:
    print(c)
elif i == 4:
    if r != 0:
        print(3)
    else:
        print(4)
elif i == 6:
    print(0)
elif i == 7:
    print(1)
else:
    print(i)
```
### B. Кольцевая линия метро

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
#### Условие

Витя работает недалеко от одной из станций кольцевой линии Московского метро, а живёт рядом с другой станцией той же линии.

Требуется определить минимальное количество промежуточных станций, мимо которых Вите необходимо проехать, чтобы добраться с работы домой.

Станции посадки и высадки учитывать не нужно.

##### Формат ввода

В одной строке записаны три целых числа:

$$
N,\ i,\ j,
$$

где:

- $N$ — общее количество станций кольцевой линии;
- $i$ — номер станции, на которой Витя садится;
- $j$ — номер станции, на которой Витя выходит.

Станции пронумерованы натуральными числами от $1$ до $N$. Первая и $N$-я станции являются соседними.

Гарантируется, что:

- $N \le 100$;
- $i \ne j$;
- все числа разделены пробелами.

##### Формат вывода

Выведите минимальное количество промежуточных станций, которые Вите необходимо проехать.

Станции посадки и высадки в ответ не включаются.

##### Пример 1

**Ввод:**

```text
100 5 6
```

**Вывод:**

```text
0
```

##### Пример 2

**Ввод:**

```text
10 1 9
```

**Вывод:**

```text
1
```

##### Примечание

В первом примере станции `5` и `6` являются соседними, поэтому Витя может доехать без промежуточных станций.

Во втором примере кратчайший путь от станции `1` до станции `9` проходит через станцию `10`, поэтому количество промежуточных станций равно `1`.
#### Решение
```python
n, i, j = map(int, input().split())
distance = abs(i - j)
print(min(distance, n - distance) - 1)
```
### C. Даты

| Ограничение | Значение |
|---|---:|
| **Время** | 2 секунды |
| **Память** | 512 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
#### Условие

Существуют два распространённых формата записи даты:

- **европейский** — сначала день, затем месяц и год;
- **американский** — сначала месяц, затем день и год.

Системный администратор изменил дату на одном из бэкапов и теперь хочет восстановить её. Однако он не знает, какой формат записи используется в системе.

Дана запись некоторой корректной даты. Требуется определить, можно ли однозначно восстановить дату, не зная формата её записи.

##### Формат ввода

В одной строке записаны три целых числа:

$$
x,\ y,\ z,
$$

где:

$$
1 \le x \le 31,
$$

$$
1 \le y \le 31,
$$

$$
1970 \le z \le 2069.
$$

Запись можно интерпретировать одним из двух способов:

- $x$ — день, $y$ — месяц, $z$ — год;
- $x$ — месяц, $y$ — день, $z$ — год.

Гарантируется, что хотя бы в одном из этих форматов запись задаёт корректную дату.

##### Формат вывода

Выведите:

- `1`, если дата определяется однозначно;
- `0`, если запись допускает две разные корректные интерпретации.

##### Пример 1

**Ввод:**

```text
1 2 2003
```

**Вывод:**

```text
0
```

##### Пример 2

**Ввод:**

```text
2 29 2008
```

**Вывод:**

```text
1
```

##### Примечание

В первом примере возможны две интерпретации:

- 1 февраля 2003 года;
- 2 января 2003 года.

Поэтому дата не определяется однозначно.

Во втором примере корректна только американская запись: 29 февраля 2008 года. Следовательно, дата определяется однозначно.
#### Решение
```python
x, y, _ = map(int, input().split())
print(int(x > 12 or y > 12 or x == y))
```
### D. Строительство школы

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
#### Условие

В деревне Интернетовка все дома расположены вдоль одной стороны улицы. На другой стороне планируют построить школу.

Место для школы необходимо выбрать так, чтобы сумма расстояний от домов всех учеников до школы была минимально возможной.

План деревни можно представить в виде прямой. Дома учеников расположены в некоторых целочисленных точках этой прямой. Школу также разрешается строить только в точке с целой координатой.

Школу можно построить напротив одного из домов, поскольку она будет находиться на другой стороне улицы.

Требуется определить координату места, в котором лучше всего построить школу.

##### Формат ввода

В первой строке записано целое число $N$ — количество учеников:

$$
0 < N < 100001.
$$

Во второй строке записаны $N$ целых чисел — координаты домов учеников. Координаты указаны в строго возрастающем порядке, и для каждой координаты $x_i$ выполняется:

$$
|x_i| \le 2 \cdot 10^9.
$$

##### Формат вывода

Выведите одно целое число — координату точки, в которой следует построить школу, чтобы сумма расстояний от домов учеников до школы была минимальной.

Если существует несколько оптимальных вариантов, выведите любой из них.

##### Пример 1

**Ввод:**

```text
4
1 2 3 4
```

**Вывод:**

```text
3
```

##### Пример 2

**Ввод:**

```text
3
-1 0 1
```

**Вывод:**

```text
0
```
#### Решение
```python
len_ = int(input())
coord = list(map(int, input().split()))
x = len_//2
print(coord[x])
```
### E. Точка и треугольник

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
#### Условие

На координатной плоскости расположен равнобедренный прямоугольный треугольник $ABC$ с длиной катета $d$ и точка $X$.

Катеты треугольника лежат на осях координат, а его вершины имеют координаты:

- $A(0, 0)$;
- $B(d, 0)$;
- $C(0, d)$.

Требуется определить взаимное расположение точки $X$ и треугольника:

- если точка находится внутри треугольника или на его границе, выведите `0`;
- если точка находится вне треугольника, выведите номер ближайшей к ней вершины.

##### Формат ввода

В первой строке записано натуральное число $d$ — длина катета треугольника:

$$
1 \le d \le 1000.
$$

Во второй строке записаны два целых числа $x$ и $y$ — координаты точки $X$:

$$
-1000 \le x,y \le 1000.
$$

##### Формат вывода

Если точка $X$ находится внутри треугольника, лежит на одной из его сторон или совпадает с одной из вершин, выведите:

```text
0
```

Если точка находится вне треугольника, выведите номер ближайшей к ней вершины:

- `1` — вершина $A$;
- `2` — вершина $B$;
- `3` — вершина $C$.

Если точка расположена на одинаковом расстоянии от нескольких вершин, выведите наименьший из их номеров.

##### Пример 1

**Ввод:**

```text
5
1 1
```

**Вывод:**

```text
0
```

##### Пример 2

**Ввод:**

```text
3
-1 -1
```

**Вывод:**

```text
1
```

##### Пример 3

**Ввод:**

```text
4
4 4
```

**Вывод:**

```text
2
```

##### Пример 4

**Ввод:**

```text
4
2 2
```

**Вывод:**

```text
0
```

##### Примечание

1. В первом примере точка находится внутри треугольника.
2. Во втором примере точка находится вне треугольника и ближе всего к вершине $A$.
3. В третьем примере точка находится на одинаковом расстоянии от вершин $B$ и $C$. Поэтому выводится вершина с меньшим номером — `2`.
4. В четвёртом примере точка лежит на стороне треугольника.
#### Решение
```python
d = int(input())
x, y = map(int, input().split())

if x >= 0 and y >= 0 and x + y <= d:
    print(0)
else:
    distances = [
        x**2 + y**2,
        (x - d)**2 + y**2,
        x**2 + (y - d)**2
    ]

    print(distances.index(min(distances)) + 1)
```
