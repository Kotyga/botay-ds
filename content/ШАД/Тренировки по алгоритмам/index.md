#### A. Кондиционер

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
##### Условие

В офисе, где работает программист Пётр, установили кондиционер нового типа. Он отличается особой простотой в управлении и имеет всего два настраиваемых параметра:

- желаемая температура;
- режим работы.

Кондиционер может работать в одном из четырёх режимов:

- **`freeze` — охлаждение.**  
  Кондиционер может только уменьшать температуру. Если температура в комнате уже не больше желаемой, кондиционер выключается.

- **`heat` — нагрев.**  
  Кондиционер может только увеличивать температуру. Если температура в комнате уже не меньше желаемой, кондиционер выключается.

- **`auto` — автоматический режим.**  
  Кондиционер может как увеличивать, так и уменьшать температуру в комнате, доводя её до желаемой.

- **`fan` — вентиляция.**  
  Кондиционер только вентилирует воздух и не изменяет температуру в комнате.

Кондиционер достаточно мощный, поэтому при подходящем режиме работы за один час доводит температуру в комнате до желаемой.

Требуется написать программу, которая по текущей температуре в комнате $t_{room}$, желаемой температуре $t_{cond}$ и режиму работы кондиционера определяет температуру, которая установится в комнате через час.

###### Формат ввода

В первой строке записаны два целых числа $t_{room}$ и $t_{cond}$, разделённые одним пробелом:

$$
-50 \le t_{room} \le 50,
\qquad
-50 \le t_{cond} \le 50.
$$

Во второй строке записано одно слово строчными латинскими буквами — режим работы кондиционера: `freeze`, `heat`, `auto` или `fan`.

###### Формат вывода

Выведите одно целое число — температуру, которая установится в комнате через час.

###### Пример 1

**Ввод:**

```text
10 20
heat
```

**Вывод:**

```text
20
```

###### Пример 2

**Ввод:**

```text
10 20
freeze
```

**Вывод:**

```text
10
```

###### Примечание

В первом примере кондиционер работает в режиме нагрева. Через час он нагреет комнату до желаемой температуры — $20$ градусов.

Во втором примере кондиционер работает в режиме охлаждения. Поскольку температура в комнате ниже желаемой, кондиционер выключается, и температура не изменяется.

##### Решение
```python
before, after = list(map(int, input().split()))
mode = input()

if mode == 'freeze':
	print(min(before, after))
elif mode == 'heat':
	print(max(before, after))
elif mode == 'fan':
	print(before)
elif mode == 'auto':
	print(after)
```

#### C. Телефонные номера

| Ограничение |                           Значение |
| ----------- | ---------------------------------: |
| **Время**   |                          1 секунда |
| **Память**  |                              64 МБ |
| **Ввод**    |   стандартный ввод или `input.txt` |
| **Вывод**   | стандартный вывод или `output.txt` |
##### Условие

Телефонные номера в адресной книге мобильного телефона могут быть записаны в одном из следующих форматов:

- `+7<код><номер>`;
- `8<код><номер>`;
- `<номер>`.

Здесь:

- `<номер>` состоит из семи цифр;
- `<код>` состоит из трёх цифр и может быть записан как с круглыми скобками, так и без них;
- если код не указан, считается, что он равен `495`;
- между любыми двумя цифрами могут стоять дефисы `-`.

Сейчас в адресной книге Васи записаны три телефонных номера. Вася хочет добавить ещё один номер, но не знает, есть ли он уже в адресной книге.

Два телефонных номера считаются одинаковыми, если у них совпадают код и семизначный номер. Например, `+7(916)0123456` и `89160123456` — это один и тот же номер.

Требуется определить, совпадает ли добавляемый номер с каждым из трёх номеров, уже записанных в адресной книге.

###### Формат ввода

В первой строке записан номер телефона, который Вася хочет добавить в адресную книгу.

В следующих трёх строках записаны номера, которые уже находятся в адресной книге Васи.

Гарантируется, что каждый номер соответствует одному из форматов, описанных в условии.

###### Формат вывода

Для каждого из трёх номеров в адресной книге выведите в отдельной строке:

- `YES`, если он совпадает с номером, который Вася хочет добавить;
- `NO`, если номера не совпадают.

###### Пример 1

**Ввод:**

```text
8(495)430-23-97
+7-4-9-5-43-023-97
4-3-0-2-3-9-7
8-495-430
```

**Вывод:**

```text
YES
YES
NO
```

###### Пример 2

**Ввод:**

```text
86406361642
83341994118
86406361642
83341994118
```

**Вывод:**

```text
NO
YES
NO
```

###### Пример 3

**Ввод:**

```text
+78047952807
+78047952807
+76147514928
88047952807
```

**Вывод:**

```text
YES
NO
YES
```

##### Решение
```python
def normalize(num: str):
    num = (
        num.replace('-', '')
           .replace('(', '')
           .replace(')', '')
           .replace('+', '')
           .replace(' ', '')
    )

    if len(num) < 11:
        num = '8495' + num

    num = '8' + num[1:]
    return num


check_number = normalize(input())

for _ in range(3):
    current_number = normalize(input())

    if check_number == current_number:
        print("YES")
    else:
        print("NO")
```

```python
a = int(input())
b = int(input())

if c < 0:
    print('NO SOLUTION')

elif a == 0:
    if b == c * c:
        print('MANY SOLUTIONS')
    else:
        print('NO SOLUTION')

else:
    numerator = c * c - b

    if numerator % a == 0:
        x = numerator // a

        print('NO SOLUTION')
```

#### E. Скорая помощь

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
##### Условие

Бригада скорой помощи выехала по вызову в один из отдалённых районов. Когда диспетчер получил вызов, он успел записать только адрес дома и номер квартиры $K_1$, после чего связь прервалась.

Однако диспетчер вспомнил, что некоторое время назад скорая помощь уже выезжала по этому адресу — в квартиру $K_2$, которая находится в подъезде $P_2$ на этаже $N_2$.

Известно, что:

- в доме $M$ этажей;
- количество квартир на каждой лестничной площадке одинаково.

Требуется определить номер подъезда $P_1$ и номер этажа $N_1$, на котором расположена квартира $K_1$.

###### Формат ввода

В одной строке записаны пять положительных целых чисел:

$$
K_1,\ M,\ K_2,\ P_2,\ N_2.
$$

Все числа не превосходят $10^6$.

###### Формат вывода

Выведите два числа — $P_1$ и $N_1$.

- Если входные данные не позволяют однозначно определить $P_1$ или $N_1$, вместо соответствующего числа выведите `0`.
- Если входные данные противоречивы, выведите:

```text
-1 -1
```

###### Пример 1

**Ввод:**

```text
89 20 41 1 11
```

**Вывод:**

```text
2 3
```

###### Пример 2

**Ввод:**

```text
11 1 1 1 1
```

**Вывод:**

```text
0 1
```

###### Пример 3

**Ввод:**

```text
3 2 2 2 1
```

**Вывод:**

```text
-1 -1
```
##### Решение
```python
K1, M, K2, P2, N2 = map(int, input().split())

# В подъезде не может быть этажа с номером больше M
if N2 > M:
    print(-1, -1)
else:
    # Номер лестничной площадки квартиры K2, начиная с нуля
    s = (P2 - 1) * M + (N2 - 1)

    # Минимально возможное количество квартир на площадке
    q_min = (K2 + s) // (s + 1)

    if s == 0:
        # Если K2 находится на первой площадке,
        # верхней границы для q нет
        q_max = None
    else:
        q_max = (K2 - 1) // s

    if q_max is not None and q_min > q_max:
        print(-1, -1)
    else:
        # При неограниченном q достаточно проверить значения до K1:
        # при q >= K1 квартира K1 всегда находится на первой площадке.
        end = q_max if q_max is not None else max(q_min, K1)

        possible_entrances = set()
        possible_floors = set()

        for q in range(q_min, end + 1):
            platform = (K1 - 1) // q

            entrance = platform // M + 1
            floor = platform % M + 1

            possible_entrances.add(entrance)
            possible_floors.add(floor)

        P1 = possible_entrances.pop() if len(possible_entrances) == 1 else 0
        N1 = possible_floors.pop() if len(possible_floors) == 1 else 0

        print(P1, N1)
```

#### F. Расстановка ноутбуков

#####  Условие

В школе решили поставить два прямоугольных ноутбука на один прямоугольный стол.

Ноутбуки необходимо расположить так, чтобы их стороны были параллельны сторонам стола. Каждый ноутбук можно поворачивать на $90^\circ$.

Определите размеры стола, на котором поместятся оба ноутбука и площадь которого будет минимально возможной.

###### Формат ввода

###### Формат вывода

Если существует несколько подходящих вариантов, выведите любой из них.

**Ввод:**

```text

```

**Возможные варианты вывода:**

```text
20 2
```

или

```text
2 20
```

или

```text
4 10
```

или

```text
10 4
```

###### Пример 2

**Ввод:**

```text
5 7 3 2
```

**Возможные варианты вывода:**

```text
9 5
```

или

```text
5 9
```

###### Примечание

В примерах перечислены все возможные ответы. Программа должна вывести только один из них.
##### Решение
```python
a, b, c, d = map(int, input().split())

variants = [
    (a + c, max(b, d)),
    (a + d, max(b, c)),
    (b + c, max(a, d)),
    (b + d, max(a, c))
]

answer = min(variants, key=lambda size: size[0] * size[1])

print(*answer)
```

#### G. Детали

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
##### Условие

Имеется $N$ кг металлического сплава. Из него изготавливают заготовки массой $K$ кг каждая.

Затем из каждой заготовки вытачивают максимально возможное количество деталей массой $M$ кг каждая.

Оставшийся после изготовления деталей материал возвращают в начало производственного цикла и сплавляют с остатком, полученным при изготовлении заготовок. Если полученного сплава достаточно для изготовления хотя бы одной новой заготовки, цикл повторяется:

1. из сплава изготавливают заготовки;
2. из каждой заготовки вытачивают максимально возможное количество деталей;
3. остатки материала снова переплавляют.

Требуется определить, сколько деталей можно получить из исходных $N$ кг сплава по описанной технологии.

###### Формат ввода

В одной строке записаны три натуральных числа:

$$
N,\ K,\ M.
$$

Все числа не превосходят $200$.

###### Формат вывода

Выведите одно целое число — количество деталей, которое можно изготовить по описанной технологии.

###### Пример 1

**Ввод:**

```text
10 5 2
```

**Вывод:**

```text
4
```

###### Пример 2

**Ввод:**

```text
13 5 3
```

**Вывод:**

```text
3
```

###### Пример 3

**Ввод:**

```text
14 5 3
```

**Вывод:**

```text
4
```
##### Решение
```python
N, K, M = map(int, input().split())

if N < K or M > K:
    print(0)
else:
    details_per_blank = K // M
    metal_spent = details_per_blank * M

    blanks = (N - K) // metal_spent + 1
    print(blanks * details_per_blank)
```

#### H. Метро

| Ограничение | Значение |
|---|---:|
| **Время** | 1 секунда |
| **Память** | 64 МБ |
| **Ввод** | стандартный ввод или `input.txt` |
| **Вывод** | стандартный вывод или `output.txt` |
##### Условие

На некоторых кросс-платформенных станциях метро на разные стороны одной платформы приходят поезда разных направлений.

Таня договорилась встретиться с подругой на такой станции, но ей пришлось долго ждать. Поезда ходят точно по расписанию и стоят у платформы ровно одну минуту.

Интервал, в течение которого поезда у платформы нет, составляет:

- $a$ минут для поездов на первом пути;
- $b$ минут для поездов на втором пути.

Таким образом, на первый путь приезжает поезд и стоит одну минуту, затем в течение $a$ минут поезда у платформы нет, после чего на одну минуту приезжает следующий поезд. Для второго пути расписание устроено аналогично.

За время ожидания Таня насчитала:

- $n$ поездов на первом пути;
- $m$ поездов на втором пути.

Все поезда, которые видела Таня, она наблюдала в течение всей минуты. Иными словами, Таня не приходила и не уходила с платформы посередине минуты, когда у платформы стоял поезд.

Требуется определить минимальное и максимальное время, которое Таня могла провести на платформе. Если указанные количества поездов несовместимы, необходимо сообщить, что Таня ошиблась при подсчёте.

###### Формат ввода

Вводятся четыре целых числа, каждое в отдельной строке:

1. $a$ — интервал между поездами на первом пути;
2. $b$ — интервал между поездами на втором пути;
3. $n$ — количество поездов на первом пути, которые увидела Таня;
4. $m$ — количество поездов на втором пути, которые увидела Таня.

Для всех чисел выполняется:

$$
1 \le a,b,n,m \le 1000.
$$

###### Формат вывода

Если данные непротиворечивы, выведите два числа:

- минимальное возможное время пребывания Тани на платформе;
- максимальное возможное время пребывания Тани на платформе.

Если Таня точно ошиблась при подсчёте поездов, выведите:

```text
-1
```

###### Пример 1

**Ввод:**

```text
1
3
3
2
```

**Вывод:**

```text
5 7
```

###### Пример 2

**Ввод:**

```text
1
5
1
2
```

**Вывод:**

```text
-1
```

```python
a, b, c, d, e, f = map(float, open(0).read().split())

# Проверяем уравнения вида 0x + 0y = ненулевое число
if (a == 0 and b == 0 and e != 0) or \
   (c == 0 and d == 0 and f != 0):
    print(0)

# Оба уравнения имеют вид 0 = 0
elif a == 0 and b == 0 and c == 0 and d == 0:
    print(5)

else:
    determinant = a * d - b * c

    # Единственное решение
    if determinant != 0:
        x = (e * d - b * f) / determinant
        y = (a * f - e * c) / determinant
        print(2, x, y)

    else:
        # Прямые параллельны, но не совпадают
        if a * f != c * e or b * f != d * e:
            print(0)

        else:
            # Уравнения задают одну и ту же прямую.
            # Выбираем одно нетривиальное уравнение.
            if a != 0 or b != 0:
                A, B, E = a, b, e
            else:
                A, B, E = c, d, f

            if A == 0:
                # By = E, то есть y фиксирован
                print(4, E / B)

            elif B == 0:
                # Ax = E, то есть x фиксирован
                print(3, E / A)

            else:
                # Ax + By = E
                # y = -A/B * x + E/B
                k = -A / B
                n = E / B
                print(1, k, n)
```
